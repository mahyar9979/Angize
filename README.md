# DARK MIND

سایت شخصی ویدیوهای انگیزشی کوتاه (فارسی + انگلیسی). بدون سرور و بدون هزینه: سایت استاتیک + یک Job روزانه در GitHub Actions که از YouTube Data API ویدیوهای واقعی را پیدا و در `data/videos.json` ذخیره می‌کند.

## راه‌اندازی (حدود ۱۰ دقیقه، رایگان)
1. یک ریپوی **عمومی** در GitHub بسازید و همهٔ فایل‌های این پوشه را آپلود کنید.
2. کلید API: در Google Cloud Console پروژه بسازید، «YouTube Data API v3» را فعال کنید و یک API key بسازید (رایگان، سهمیهٔ روزانه ۱۰٬۰۰۰ واحد).
3. در ریپو: Settings ← Secrets and variables ← Actions ← New repository secret ← نام `YOUTUBE_API_KEY` و مقدار کلید.
4. تب Actions ← «Daily video discovery» ← Run workflow (اولین اجرا، دستی). بعد از آن هر روز خودکار اجرا می‌شود.
5. Settings ← Pages ← Source: «Deploy from a branch» ← main / root. آدرس سایت همان‌جا نمایش داده می‌شود.
6. گوشی: آیفون (Safari): Share ← Add to Home Screen. اندروید (Chrome): Menu ← Install app.

## ویرایش عبارت‌های جست‌وجو
فایل `config/queries.json` را در گیت‌هاب ویرایش کنید (`enabled` یا `q`). هر اجرا حداکثر ۳۰ عبارت (حدود ۳٬۰۰۰ واحد سهمیه) را به‌نوبت اجرا می‌کند.

## محدودیت‌ها
- ذخیره‌ها و تاریخچه فقط در مرورگر همان دستگاه هستند (همگام‌سازی بین دستگاه‌ها ندارد؛ پشتیبان‌گیری در تنظیمات هست).
- جست‌وجو فقط بین ویدیوهای جمع‌آوری‌شده است، نه جست‌وجوی زندهٔ یوتیوب.
- زیرنویس فارسی برای ویدیوهای انگلیسی پیاده‌سازی نشده.
- زبان ویدیو از متادیتای یوتیوب و تحلیل متن حدس زده می‌شود و ممکن است گاهی اشتباه باشد.
- «ادمین» فقط صفحهٔ وضعیت فقط‌خواندنی است (`#/status`)؛ اجرای دستی و ویرایش از طریق GitHub انجام می‌شود، چون سایت استاتیک امن‌ترین و ارزان‌ترین گزینه است.
- GitHub ممکن است اجرای زمان‌بندی‌شده را چند دقیقه تا چند ساعت دیر اجرا کند و در ریپوی بدون فعالیت بیش از ۶۰ روز آن را غیرفعال کند.
- فونت Vazirmatn از Google Fonts بارگذاری می‌شود.
